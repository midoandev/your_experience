# Design Audit — 2026-06-12

Gabungan hasil Token Consistency Checker + UX Pattern Reviewer.

## Critical — Segera Fix

### 1. Duplicate Theme Files
`lib/core/theme/` (dipakai) vs `lib/core/ui/theme/` (legacy). Dua `app_colors.dart` dan `app_theme.dart`.
**Fix:** Hapus `core/ui/theme/` — semua view sudah pake `core/theme/`.

### 2. Portfolio-detail Route Cast Unchecked
`app_router.dart:22` — `state.extra as ProjectsData` bisa throw TypeError.
**Fix:** Validasi tipe dulu di builder.

### 3. Splash Page Masih Colors.white
Splash page & splash_vm masih hardcode `Colors.white` / `Colors.black87`.
**Fix:** Ganti ke AppColors.

### 4. Color(0xFF040E0C) 2× Hardcoded
AvailableBadge bg + PillTag teal bg — bukan dari AppColors.
**Fix:** Tambah `bgTagTeal` ke AppColors.

## Medium — Perbaiki Bertahap

### 5. HeroSection _viewCv() Tanpa try-catch
Async rootBundle.loadString() silent fail.
**Fix:** Wrap try-catch + SnackBar.

### 6. portfolio_detail_page.dart 11× Pelanggaran Spacing
Paling banyak hardcoded spacing + copyWith override text style.

### 7. About Page Dead Route
`const SizedBox()` — buat konten atau hapus route.

### 8. Workspace Save Buttons No-op
Create & Editor — `onPressed: () {}`.
