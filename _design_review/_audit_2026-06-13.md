## Critical Issues

### C1 — Theme Violates Seed-Based Principle
**File:** `lib/core/theme/app_theme.dart`
**Severity:** CRITICAL
**Detail:** Dark theme uses full `const ColorScheme.dark(primary: Color(0xFF...), ...)` with 8 hardcoded colors instead of `ColorScheme.fromSeed`. Light theme already uses seed. Follow PRINSIP 3 — seed-based theme for both modes.
**Fix:** Replace `const ColorScheme.dark(...)` with `ColorScheme.fromSeed(seedColor: AppColors.seed, brightness: Brightness.dark)`

### C2 — 3 Orphaned ViewModels
**Severity:** CRITICAL
**Detail:** ViewModels defined but never consumed by their views:
- `SplashVm` (`lib/features/splash/view_model/splash_vm.dart`) — view creates own Timer
- `ServicesVm` (`lib/features/services/view_model/services_vm.dart`) — view hardcodes data
- `FooterVm` (`lib/features/footer/view_model/footer_vm.dart`) — view only renders copyright

### C3 — 2 Missing ViewModels
**Severity:** CRITICAL
**Files:**
- `lib/features/workspace/create_portfolio/` — `create_portfolio_vm.dart` missing
- `lib/features/workspace/editor_content/` — `editor_content_vm.dart` missing
**Detail:** Architecture declares `view_model/` folders but files don't exist. Pages use raw controllers + local state. Violates MVVM contract.

### C4 — Dead Navigation
**Severity:** CRITICAL
**File:** `lib/features/portfolio/view/portfolio_section.dart` → `lib/core/router/app_router.dart`
**Detail:** `_SeeAllButton` calls `context.pushNamed('projects')` but GoRouter has no `/projects` route. App crashes on tap.

### C5 — Hardcoded fontSize in Theme Definition
**File:** `lib/core/theme/app_theme.dart` (±156-198)
**Severity:** CRITICAL
**Detail:** `copyWith(fontSize: 36, 24, 22, 13, 14, 11, 12, 10)` — font sizes hardcoded in theme definition. Should use `GoogleFonts.getTextTheme()` or define named text styles.
